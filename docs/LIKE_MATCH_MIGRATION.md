# Технический план миграции `like=match` → «Я подписан / Мои подписки»

## Ограничение

- Визуальный дизайн страницы **не меняем**.

## Что меняем

1. Текстовые ресурсы интерфейса:
   - заголовки,
   - подписи вкладок,
   - empty-state тексты.
2. Источники данных:
   - старая логика `like/match` удаляется,
   - подключаются эндпоинты подписок/подписчиков.
3. Аналитика:
   - новые события для просмотра вкладок и переходов в профиль креатора.

## Пошаговый rollout

1. Добавить новый слой API-клиента для `following/subscribers`.
2. Переключить страницу на новые данные под feature-flag.
3. Проверить parity по UI (визуально без изменений).
4. Включить флаг на 10% пользователей, затем на 100%.
5. Удалить legacy-код `like/match` после стабилизации.

## Критерии готовности

- Оба таба открываются без ошибок.
- Данные соответствуют серверу.
- Не изменён внешний вид страницы.
- Ошибки и задержки мониторятся в логах/метриках.
