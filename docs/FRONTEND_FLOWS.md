# Frontend: состояния и пользовательские сценарии MVP

## 1) Лента

- Вертикальная full-screen лента (1 пост на экран).
- Жесты: swipe up/down для перехода между элементами.
- Карточка поста:
  - медиа,
  - автор,
  - кнопки: подписка, unlock (если PPV), донат.
- Состояния:
  - `loading` (скелетон)
  - `ready`
  - `paywalled` (закрытый контент)
  - `error`

## 2) Профиль креатора (TikTok-style)

- Шапка: аватар, имя, био, счётчики, статус верификации.
- CTA: подписаться / отправить донат.
- Список контента: табы «Видео/Фото».
- Состояния:
  - `not_verified` (для автора показываем кнопку «Пройти верификацию» в меню)
  - `verified`

## 3) Paywall-сценарии

- `subscribers_only`: показываем CTA «Оформить подписку».
- `ppv`: показываем CTA «Открыть за N».
- После успешной оплаты — мгновенное раскрытие контента без перезагрузки экрана.

## 4) Донаты

- Быстрые суммы (preset кнопки) + кастомная сумма.
- Опциональное сообщение креатору.
- После оплаты: тост «Донат отправлен» + обновление локальной статистики.

## 5) like=match без редизайна

- Сохраняем текущий визуал страницы.
- Меняем только тексты, источники данных и названия вкладок:
  - «Я подписан» → `GET /api/v1/me/following`
  - «Мои подписки» → `GET /api/v1/me/subscribers`
