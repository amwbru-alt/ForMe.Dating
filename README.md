# ForMe.Dating

Монорепозиторий продукта ForMe.Dating — гибрида OnlyFans и TikTok с входом через Telegram.

## Концепция продукта

- От OnlyFans: платные подписки, платный доступ к фото/видео и донаты авторам.
- От TikTok: профиль в стиле creator-page и вертикальная swipe-лента коротких видео/фото.
- Авторизация: вход через Telegram; отдельной регистрации внутри продукта нет.
- Для роли креатора: запуск верификации из меню пользователя.
- Страница `like=match` сохраняет текущий визуальный дизайн, но функционально используется как разделы «Я подписан» и «Мои подписки».
